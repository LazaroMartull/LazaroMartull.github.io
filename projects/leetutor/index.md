# LeetTutor – AI-Powered Programming Tutor

## Overview
LeetTutor is an AI-driven tutoring system designed to provide structured, step-by-step programming guidance to post-secondary students. The system leverages large language models to simulate human-like tutoring interactions while maintaining clarity and instructional depth.

This work is part of the research paper:
**"LeafTutor: An AI Agent for Programming Assignment Tutoring" (arXiv, 2025).**

## Problem
High enrollment in STEM programs has created increasing demand for scalable programming tutoring solutions. Traditional tutoring resources are limited and difficult to scale.

## Solution
LeetTutor delivers:
- Step-by-step programming explanations
- Structured reasoning
- Personalized learning support
- Guided problem-solving assistance

## Tech Stack
- Python
- Flask
- PostgreSQL
- LLM API (Gemini / GPT-style models)
- Prompt engineering
- Evaluation framework

## Evaluation
Evaluated using real programming assignments; results indicate the system can deliver step-by-step programming guidance comparable to human tutors.
