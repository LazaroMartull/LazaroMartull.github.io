# 📚 Publications

## LeafTutor: An AI Agent for Programming Assignment Tutoring  
**arXiv (2025)**  

Co-authored research on an LLM-powered tutoring system designed to provide step-by-step programming guidance comparable to human tutors.

### Overview
LeafTutor addresses the growing demand for scalable programming support in post-secondary STEM education. The system was evaluated using real programming assignments and demonstrated strong instructional capability.

### Key Contributions
- Developed and evaluated an AI-driven tutoring agent
- Designed structured, step-by-step solution generation
- Applied large language models to real-world academic use cases
- Contributed to system evaluation and validation
